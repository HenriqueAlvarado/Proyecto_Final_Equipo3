2. COMPONENTES COMUNES (src/components/common/)
================================================================================

2.1 Button.jsx
--------------
Boton reutilizable con variantes de estilo, tamano y estado de carga.

Props:
  children    ReactNode  Contenido del boton
  variant     string     'primary'|'secondary'|'danger'|'outline' (default: primary)
  size        string     'sm'|'md'|'lg' (default: md)
  disabled    boolean    Deshabilita el boton (default: false)
  loading     boolean    Muestra spinner y deshabilita (default: false)
  onClick     function   Manejador de clic
  type        string     'button'|'submit'|'reset' (default: button)
  fullWidth   boolean    Ocupa 100% del ancho (default: false)

Variantes:
  primary   Fondo azul #1a73e8, texto blanco
  secondary Fondo verde #34a853, texto blanco
  danger    Fondo rojo #ea4335, texto blanco
  outline   Fondo transparente, borde y texto azul

Accesibilidad: aria-disabled cuando loading/disabled, spinner con aria-hidden

Ejemplo:
  <Button variant="danger" size="sm" loading={isLoading} onClick={handleDelete}>
    Eliminar
  </Button>


2.2 Input.jsx
-------------
Campo de entrada con label, validacion visual y accesibilidad.

Props:
  label       string    Texto de la etiqueta
  error       string    Mensaje de error (borde rojo + texto)
  id          string    Requerido para asociar label con input
  type        string    Tipo HTML del input (default: text)
  placeholder string    Texto de placeholder
  value       string    Valor controlado
  onChange    function  Manejador de cambio
  required    boolean   Muestra asterisco en label (default: false)
  disabled    boolean   Deshabilita el campo (default: false)

Accesibilidad: aria-invalid cuando hay error, aria-describedby al mensaje de error

2.3 Card.jsx
------------
Contenedor con fondo blanco, bordes redondeados y sombra.
Props: children, title (opcional, con linea separadora), className

2.4 Navbar.jsx
--------------
Barra superior fija. Muestra logo, nombre del sistema, usuario autenticado y
boton de cerrar sesion. Lee datos de AuthContext. No recibe props.

2.5 Sidebar.jsx
----------------
Menu lateral fijo con navegacion filtrada por rol del usuario.
Items por rol:
  recepcionista  Dashboard, Agenda, Pacientes, Medicos
  medico         Dashboard, Agenda
  director       Dashboard, Medicos, Usuarios
  paciente       Mis citas
Usa NavLink para resaltar la ruta activa. No recibe props.

3. COMPONENTES DE AUTENTICACION (src/components/auth/)
================================================================================

3.1 LoginForm.jsx
------------------
Formulario de login para personal clinico (tab 'Personal clinico').
Flujo: email+password -> validacion local -> authService.login() -> navigate('/dashboard')
Validaciones: email formato valido, password requerido

3.2 LoginPacienteForm.jsx
--------------------------
Formulario de login para pacientes (tab 'Soy paciente').
Flujo: email+password -> authService.loginPaciente() -> navigate('/mis-citas')
Usa endpoint /api/auth/login-paciente (busca en tabla pacientes, no usuarios)


================================================================================
4. COMPONENTES DE CITAS (src/components/appointments/)
================================================================================

4.1 AgendaView.jsx
-------------------
Tabla de citas por fecha con selector de fecha y boton nueva cita.
Props: onNew, onEdit(cita), onCancel(cita)
Carga citas al montar y al cambiar fecha. Medicos solo ven sus propias citas.
Badges: programada=azul, completada=verde, cancelada=rojo
Endpoint: GET /api/citas?fecha=YYYY-MM-DD

4.2 CreateAppointmentForm.jsx
------------------------------
Formulario para crear cita. Campos: buscar paciente, medico, fecha, hora, motivo.
Busqueda de paciente en tiempo real (minimo 2 caracteres).
Endpoint: POST /api/citas

4.3 EditAppointmentForm.jsx
----------------------------
Modifica fecha, hora y motivo de una cita programada.
Props: cita, onSuccess, onCancel
Endpoint: PUT /api/citas/:id

4.4 CancelAppointmentModal.jsx
-------------------------------
Modal de confirmacion para cancelar cita. Muestra paciente y medico.
Props: cita, onSuccess, onClose
Accesibilidad: role=dialog, aria-modal, aria-labelledby
Endpoint: PATCH /api/citas/:id/cancelar

5. COMPONENTES DE PACIENTES (src/components/patients/)
================================================================================

5.1 PatientList.jsx
--------------------
Tabla de pacientes con modales de detalle y eliminacion.
Props: patients, onDeleted

Ver detalle: modal con nombre, correo, telefono, fecha nacimiento, CURP, direccion
Eliminar: modal de confirmacion -> DELETE /api/pacientes/:id (borrado logico)
  Si tiene citas programadas, el backend rechaza con mensaje explicativo
  Tras eliminar, llama a onDeleted() para recargar la lista

5.2 PatientForm.jsx
--------------------
Registra nuevo paciente con credenciales de acceso.
Campos: nombre*, apellido*, correo*, contrasena* (min 6), telefono*, fecha_nacimiento*, CURP, direccion
Tras registro exitoso: muestra email y contrasena en pantalla para entregarselos al paciente
Endpoint: POST /api/pacientes

5.3 PatientSearch.jsx
----------------------
Barra de busqueda por nombre, correo o CURP.
Props: onSearch(query)
Endpoint: GET /api/pacientes/buscar?q=

10. SERVICIOS API (src/services/)
================================================================================

Todos usan la instancia Axios de api.js.

api.js:
  baseURL    REACT_APP_API_URL (.env)
  timeout    10000ms
  Interceptor request:  agrega Authorization: Bearer <token>
  Interceptor response: si 401 -> limpia sesion y redirige a /login

authService.js:
  login(email, password)           POST /auth/login
  loginPaciente(email, password)   POST /auth/login-paciente
  logout()                         Limpia localStorage
  registerUser(data)               POST /auth/register
  getUsuarios()                    GET  /auth/usuarios
  toggleUsuario(id)                PATCH /auth/usuarios/:id/toggle
  getMisCitas()                    GET  /auth/mis-citas

appointmentService.js:
  getAppointmentsByDate(fecha)     GET  /citas?fecha=
  createAppointment(data)          POST /citas
  updateAppointment(id, data)      PUT  /citas/:id
  cancelAppointment(id)            PATCH /citas/:id/cancelar
  getMyAppointments()              GET  /citas/mis-citas

patientService.js:
  getPatients()                    GET  /pacientes
  searchPatients(query)            GET  /pacientes/buscar?q=
  createPatient(data)              POST /pacientes
  getPatientById(id)               GET  /pacientes/:id
  deletePatient(id)                DELETE /pacientes/:id

doctorService.js:
  getDoctors()                     GET  /medicos
  getDoctorById(id)                GET  /medicos/:id

11. HOOKS Y CONTEXTO
================================================================================

useAuth.js: acceso a AuthContext. Retorna: user, login, loginPaciente, logout, loading
useForm.js: manejo generico de formularios con validacion por campo

AuthContext.jsx:
  Provee: user, login, loginPaciente, logout, loading
  Persiste sesion en localStorage (token + user)
  loading=true mientras verifica sesion al cargar la app
  Roles: recepcionista, medico, director, paciente
